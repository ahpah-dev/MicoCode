# MicoCode 0.9.4 — FreeLLMAPI connection fixes

FreeLLMAPI now keeps the unified key and selected model when reconnecting to the same local endpoint. Setup reports that the dashboard is running and asks for the unified key before checking models. Connection verification uses that key through MicoCode's native relay.

- The API key field remains editable after managed setup.
- Models needing provider setup or with exhausted quota cannot be selected, including through the keyboard. Auto routing is available only when a provider is ready.
- Coding requests carry FreeLLMAPI's coding task header, and agent status reports the actual provider and failover route.
- Reconnecting reuses the running dashboard. An occupied default port falls back to another loopback port.
- Fixed a child-process launch error in the managed installer.

To connect, open Models, set up FreeLLMAPI, open its dashboard, add a provider key, then paste the dashboard's unified API key into MicoCode and click Connect & verify.

## Windows download

Download **MicoCode-Windows-0.9.4-x64.zip**, extract the entire folder, and run **MicoCode.exe**. This release provides a ZIP instead of the NSIS installer.

The app archive is built from this release's source; the launcher and Electron runtime reuse the working previous release. Windows launcher file properties may still show 0.9.3, while the app reports 0.9.4. This avoids a newly packaged Electron launcher that crashes on this build machine.

## Verification

- TypeScript check and production desktop build passed.
- All 201 tests passed using the verified Electron runtime.
- The final native app passed the workspace, bridge, provider-status, and API smoke checks in an isolated test profile.
- The browser flow was checked against a simulated FreeLLMAPI upstream: missing and invalid keys, model availability, reconnect, persistence, and an agent edit through review, apply, and preview.

Real cloud generation with a provider key remains unverified. A fresh profile also exposed an existing CORS error when auto-discovering an independently running 9Router; the release smoke check used an isolated saved profile.
